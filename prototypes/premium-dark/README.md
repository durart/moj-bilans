# Prototyp „Mój Bilans”: Premium Dark

- Adres po publikacji: `https://durart.github.io/moj-bilans/prototypes/premium-dark/`
- Prototyp interaktywny (dziennik, szukanie, edycja gramatury nowego produktu, historia, pomiary, woda).
- **To nie jest produkcyjna aplikacja:** nie odczytuje `localStorage`, IndexedDB ani danych osobowych; nie używa internetu, zewnętrznych API, service workera i nie zapisuje zmian na dysku. Wszystkie wartości to dane demonstracyjne, resetowane po odświeżeniu.
- Pojedynczy folder odizolowany od aplikacji `https://durart.github.io/moj-bilans/`, ze względnymi plikami i bez importów z katalogu produkcyjnego.
- Porównanie wyglądu służy do wyboru kierunku projektu; późniejsze wdrożenie wymaga osobnego zadania i testów migracyjnych/regresyjnych.
